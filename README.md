# MINPRO-2
#JUDUL # Program CRUD Python dengan Sistem Login
deskripsi singkat Program ini dibuat untuk memenuhi Mini Project 2.
Program menerapkan konsep CRUD (Create, Read, Update, Delete) 
dengan sistem login dan dua role pengguna, yaitu Manager dan Karyawan.
fitur program Login dengan username & password

Role Manager:

Create Data

Read Data


Update Data

Delete Data


Role Karyawan:

Hanya bisa Read Data


Sistem looping menu & error handling

cara menjalanakan program
1. Install Python (minimal versi 3.8)
2. Clone repository ini atau download file .zip
3. Buka terminal/cmd
4. Jalankan program dengan perintah:
   python main.py
